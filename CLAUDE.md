# studyAI

## Video editing (Remotion / Reels pipeline)

Before creating, editing, or reviewing any Remotion composition under
`clean_website/artifacts/video-renderer` (the pipeline driven by
`clean_website/scripts/src/marketing/video-agent.ts`), use the
`remotion-video-editing` skill (`.claude/skills/remotion-video-editing/SKILL.md`).
It encodes the house style — an authenticity/QA gate plus three concrete
formats (cinematic camera movement, terminal-insert cards, article-highlight
cards) — so every reel stays visually consistent instead of each session
inventing its own approach.
